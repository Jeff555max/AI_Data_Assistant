# AI Data Assistant

AI-чат на FastAPI + Jinja2 + HTMX, который использует OpenAI API для ответов по данным и анализа изображений, а локально строит графики и сохраняет артефакты в файлы.

## Что умеет

•	Мультиформатная загрузка: Ассистент поддерживает прием и парсинг табличных данных в форматах CSV, Excel, JSON, PDF (текстовый слой/OCR), а также работу с изображениями, инфографикой.

•	Интеллектуальный анализ: Система может принимать обычные текстовые сообщения и использовать модели OpenAI для глубокого анализа контекста, структурированных данных и изображений (с помощью Vision).

•	Визуализация: Ассистент способен автоматически строить графики типов line (линейные), bar (столбчатые) и histogram (гистограммы) и выводить их в формате PNG.

•	Генерация отчетов: Реализована возможность автоматической сборки полноценных аналитических отчетов в формате DOCX.

•	Саммаризация результатов: Ассистент умеет формировать и сохранять краткие итоги своей работы в виде markdown-summary.

•	Управление артефактами: Все сгенерированные файлы (графики и текстовые отчеты) можно просматривать и скачивать непосредственно в интерфейсе чата.


## Пример использования
Такой ассистент может быть полезен в различных сценариях: для владельцев бизнеса, для специалистов по работе с данными или для всех, кто нуждается в автоматизации аналитических задач. Ассистент помогает оптимизировать рабочие процессы, ускоряя построение графиков и формирование отчетности.
Особенность такого решения — в его гибкости. Благодаря широкому промпту, заложенному в основу, ассистент не ограничивается узкой задачей вроде построения графиков, а охватывает множество аспектов анализа данных. При необходимости его можно легко адаптировать под конкретную задачу — достаточно доработать промпт.
Взаимодействие с ассистентом осуществляется через веб-интерфейс: мы можем общаться с ним, запрашивать информацию, получать файлы и готовые графики.

## Структура проекта

```text
AI_Data_Assistant/
├── app/
│   ├── main.py                  # Точка входа FastAPI, подключение роутов и static/storage
│   ├── core/
│   │   ├── config.py            # Настройки приложения, лимиты загрузки, OpenAI и OCR
│   │   └── logging.py           # Настройка логирования
│   ├── routes/
│   │   ├── pages.py             # Страницы чата, preview и результатов
│   │   ├── upload.py            # Загрузка файлов
│   │   ├── chat.py              # Сообщения в чате и переключение активного файла
│   │   └── actions.py           # Анализ, графики, отчёты и скачивание артефактов
│   └── services/
│       ├── file_service.py      # Сохранение файлов, preview, чтение таблиц/PDF/OCR/изображений
│       ├── analysis_service.py  # Локальный анализ таблиц, изображений и PDF
│       ├── chart_service.py     # Генерация PNG-графиков
│       ├── report_service.py    # Генерация DOCX-отчётов
│       ├── export_service.py    # Markdown-summary
│       ├── chat_service.py      # Логика диалога, действий и сохранённых артефактов
│       └── ai_service.py        # Интеграция с OpenAI Responses API
├── templates/
│   ├── base.html                # Общий HTML-каркас
│   └── partials/                # HTMX-фрагменты интерфейса
├── static/
│   ├── css/styles.css           # Стили интерфейса
│   └── js/app.js                # Клиентская логика HTMX, формы и прогресс обработки
├── storage/
│   ├── uploads/                 # Загруженные файлы и metadata
│   └── outputs/                 # Сгенерированные графики, отчёты и summary
├── examples/                    # Пример CSV/XLSX данных
├── tests/                       # Unit-тесты сервисов и PDF/OCR сценариев
├── Dockerfile                   # Docker-образ приложения
├── docker-compose.yml           # Запуск контейнера через Docker Compose / Docker Desktop
├── requirements.txt             # Python-зависимости
├── .env.example                 # Пример переменных окружения
└── README.md                    # Документация проекта
```


## Настройка OpenAI

Добавьте в `.env`:

```env
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-4o
OPENAI_MAX_HISTORY_MESSAGES=8
```

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000`.

## Docker

```bash
docker-compose up --build -d
```
